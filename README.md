<br />

## Description

OpenSya Core is the runtime behind OpenSya, the open-source recruitment infrastructure for modern companies.

It orchestrates the server, client, configuration and modules of an OpenSya application through a consistent, convention-driven architecture.

Built with Fastify, Vue, Vite and TypeScript, Core provides the foundation for creating recruitment platforms that are modular, extensible and fully owned by the organizations that run them.

## Philosophy

- **Follow conventions**

Predictable structures replace repetitive configuration and let teams focus on their business domain.

- **Compose capabilities**

Applications are built from independent modules that can extend both the server and the client.

- **Stay in control**

Organizations own their code, data, infrastructure and the way their recruitment platform evolves.

## Features

- Convention-driven full-stack runtime
- Fastify server runtime
- Vue and Vite client runtime
- Application and module configuration
- Automatic module discovery and composition
- Server and client extensibility
- End-to-end TypeScript development
- Development and build orchestration

---

> OpenSya Core is under active development and is not yet ready for production use.
